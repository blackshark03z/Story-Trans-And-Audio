# Story Audio Product Goal gap map

Assessment date: 2026-08-09. This records current evidence against the frozen
Product Goal; it does not authorize implementation.

## Working

- Multiple EPUB import and book/chapter selection.
- Character registry, Character Bible support, and reuse of established
  character/casting context within a book.
- Gemini Speaker Assignment Drafts with human review and immutable approval.
- Production readiness, separate PREPARE/START_RENDER boundaries, checkpointed
  rendering, listening/QA, explicit acceptance, and downloadable active audio.
- Batch/range projection with independent per-chapter job and artifact state.

## Partial

- Voice management: book defaults/overrides and custom-voice assignment work,
  but the custom voice library is historically global rather than truly
  book-owned.
- Unknown-character proposals exist, but the approved main/supporting/minor or
  crowd role taxonomy is not established as a complete operator workflow.
- Timestamp-oriented diagnosis and targeted repair exist, but durable operator
  timestamp feedback through every repair/review step needs product-goal
  acceptance evidence.
- MP3/WAV availability exists in artifacts/workflows, but the exact frozen
  download promise needs one representative end-to-end acceptance demonstration.

## Missing or not yet demonstrated against this goal

- Enforced book-scoped custom voice ownership without cross-book default sharing.
- A single completed North Star demonstration covering every frozen step from
  import through accepted MP3/WAV download under the new product terminology.
- Product UI consistently using BOOK / CHARACTER / VOICE / CHAPTER / AUDIO
  rather than exposing internal workflow entities except for recovery detail.

## Interpretation

Historical milestones remain evidence only. Future work must select one bounded
operator-visible gap or validation outcome and obtain its own task authority.
