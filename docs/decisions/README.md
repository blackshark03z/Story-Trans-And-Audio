## When to create a Decision Record

Create one only when losing the decision could materially change a later
session's scope, approach, acceptance, architecture, authoritative path or
expensive research. Use the CADS Decision Continuity Protocol when available.

Minimal record: `DR-xxxx` title, Status, Date, Scope, Context, Decision, Why,
Consequences, and Revisit When. Supersede accepted records; do not silently
rewrite their historical decision.
